# JY-OS Repository Map

This repository documents the structure of the **JY-OS Human Operating System**.

The project combines learning protocols, system architecture, and real-world experiments.

The repository is organized into four layers.

---

# Layer 1 — Architecture

Core system design.

Describes how the JY-OS learning system operates.

Example documents:

• AI Learning Architecture  
• JY-OS system overview

---

# Layer 2 — Protocol Library

Defines cognitive and learning protocols used by the system.

Examples:

• Civilization Layer  
• Cognitive Engine  
• CAP Reading Protocol  
• PVUL Learning Loop

---

# Layer 3 — Experiment

Real-world learning environments where the system is applied.

Current reference case:

Logan AI Learning Experiment

---

# Layer 4 — Evidence Logs

Observational records from real learning interactions.

Examples include:

• weekly experiment logs  
• learning observations  
• protocol adjustments

---

# System Flow

Architecture  
↓  
Protocols  
↓  
Experiment  
↓  
Evidence  
↓  
Protocol Evolution

---

# Purpose

The goal of this repository is to explore how **AI-assisted learning systems** can support human learning development.

The project treats learning as a **system architecture problem**, rather than a content delivery problem.
