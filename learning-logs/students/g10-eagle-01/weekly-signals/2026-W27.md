---

### Part B — Writing Planning

Before writing, student must complete:

Topic:
Position:
Reason 1:
Reason 2:
Example:
How does the example prove my reason?
Conclusion:

No writing before planning is complete.

Coach checks planning only for:

* logical connection
* example relevance
* clear position
* conclusion focus

Do not rewrite the plan.

---

### Part C — GSAT Short Writing

Student writes:

→ 120–150 words

Required structure:

Sentence 1 — Position
Sentences 2–3 — Reason 1
Sentences 4–5 — Example
Sentences 6–7 — Explanation / Reason 2
Sentence 8 — Conclusion

Conclusion requirement:

→ return to topic + slightly expand

---

### Part D — Writing Check

Student must complete after every paragraph:

Word count:
Within 120–150 words: Yes / No
Clear position: Yes / No
Reason 1 supports position: Yes / No
Reason 2 supports position: Yes / No
Example supports reason: Yes / No
Explanation connects back to position: Yes / No
Conclusion returns to topic: Yes / No
Any sentence too long: Yes / No
One sentence = one main idea: Yes / No

REDO rules:

* If word count is under 120, mark REDO.
* If there is no clear example, mark REDO.
* If example does not support reason, mark REDO.

---

### Part E — Reflection

Required:

1. What is my main position?
2. Which sentence is my strongest support?
3. Which sentence gives my example?
4. How does my example prove my reason?
5. Which sentence should be simplified?
6. Did I build an argument, or did I only give advice?
