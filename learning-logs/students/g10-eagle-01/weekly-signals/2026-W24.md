### 4. Sentence Parsing Became Mostly Automatic

Sentence Parsing was a major intake risk.

This week, Eddie showed mostly stable control of:

* Main Subject
* Main Verb
* Participial Phrase
* Core Meaning

However, two issues remain active:

1. noun clause vs relative clause confusion
2. occasional main verb selection error

The most repeated issue:

Eddie may label “that…” as a relative clause when it is actually a noun clause.

Example pattern:

If “that...” follows verbs such as:

* found
* discovered
* believe
* suggest

it is usually a noun clause.

If “that / which / who” modifies the noun before it, it is usually a relative clause.

This issue does not currently block comprehension, but it may slow down reading when sentences become longer and more GSAT-like.

Classification:

→ SENTENCE_PARSING_MOSTLY_STABLE
→ CLAUSE_CLASSIFICATION_ACTIVE_GAP
