# Student Learning Dataset

This directory contains anonymized student learning logs used in the **JY-OS Reading Judgment Lab**.

Each student folder represents an individual learning record used to observe:

* reasoning development
* learning discipline
* language skill stabilization
* reading judgment formation
* AI-assisted coaching interaction
* execution continuity and interruption patterns

The dataset documents how structured **AI coaching protocols** influence student learning trajectories over time.

---

# Folder Structure

Each student folder may include the following files or subfolders.

### profile.md

Basic student information, alias, learning track, and current status.

### learning-log.md

Chronological observations of learning behavior, training focus, and major developmental milestones.

### metrics.md

Long-term skill stability tracking across training cycles.

### milestone-log.md

Major learning transitions, breakthrough moments, or phase changes.

### weekly-signals /

Machine-readable weekly learning diagnostics used to detect emerging learning patterns.

Some students follow **biweekly reporting cycles** depending on training protocol.

### diagnostic /

Initial diagnostic reports or baseline gap analysis files.

This folder is used especially for intake students or students entering a new track.

# Status Definitions

### Active

Student is currently participating in weekly or biweekly training cycles.

### Paused

Student is temporarily not executing tasks.
Learning evaluation is suspended until task execution resumes.

### Exited

Student has left the program.
Records remain archived for trajectory analysis and system-level case study extraction.

### Intake Diagnostic

Student is in the first-stage diagnostic observation period.
The student is not yet classified as a long-term case study.

---

# Research Purpose

The student cases help document how structured AI coaching protocols influence learning outcomes.

Observed learning signals include:

* evidence-based reading
* inference reasoning
* reading model building
* writing stability
* grammar control
* output delivery discipline
* redo tolerance
* learning autonomy
* parent / environment influence
* execution continuity

The dataset is part of the **JY-OS AI Learning Experiment**, which studies how structured prompting, error-code feedback, redo systems, and protocol-driven coaching can support student skill development.

# Case Study Extraction Rule

Weekly learning logs are not automatically case studies.

A student log may later become a case study only when a repeatable system pattern appears.

Examples of extractable patterns:

* signal vs perception mismatch
* dependency vs autonomy
* scaffold removal and transfer
* public-school fit boundary
* reading model transition
* output compliance stabilization
* low-volume skill stability

Case studies should be stored separately from raw student learning logs.

# Privacy Notice

All student identities are anonymized.

Animal aliases are used to protect student privacy while preserving longitudinal learning records.

The dataset is intended for internal research, system design, and future JY-OS Playbook development.
