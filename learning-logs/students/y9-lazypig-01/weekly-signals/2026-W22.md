## Final Instruction

Do not stop at explanation.

Every advanced response must include:

1. specific mechanism
2. concrete implication
3. condition or limitation
4. precise academic language
5. specific evidence or named example
6. long-term system consequence
7. human-system evaluation when relevant
8. final justified judgment

If the answer explains impacts but not mechanisms, it is incomplete.
If the answer names stakeholders but does not explain power, it is incomplete.
If the answer uses SDGs as labels instead of evaluation frameworks, it is incomplete.
If chemistry explains both sides but does not compare them directly, the evaluation is incomplete.
