# IB Subject Selection Tracker — Logan Experiment

This tracker monitors Logan’s academic development in key IB subjects.

The goal is to observe learning stability and reasoning development over time to support future IB subject selection.

Tracked subjects focus on areas relevant to future **H3 / H4 decisions**.

# Selection Logic

Future IB subject selection will consider:

• reasoning strength  
• academic stability  
• long-term interest  
• workload balance  

The tracker does not make final decisions.

Instead, it provides **longitudinal observation data**.

---

# Data Source

This tracker is informed by:

• weekly experiment logs  
• AI coach telemetry signals  
• academic observations

---

# Purpose

Many IB students select subjects based on short-term performance.

The Logan Experiment aims to support subject decisions using **longitudinal learning signals** instead.

This allows academic decisions to be based on **learning development patterns**, not single exam results.
