# Case 016 — Exit Pattern Analysis

## Context

Two students exited the program after extended participation (≈10 months).

Reference cases:
- Case 014 — Phoebe
- Case 015 — Audrey

---

## Shared Signal Pattern

Across both cases:

- structural progress: present  
- execution consistency: unstable  
- complaints: high  
- parent involvement: high  

---

## Converging Conditions

Exit occurred under the following combined conditions:

- execution < threshold (≈4 sessions/week)  
- learning friction increased  
- progress remained low-visibility (structure/control level)  
- perception relied on short-term observable change  

---

## Failure Mechanism

1. learning progresses in structural layer (low visibility)  
2. execution consistency drops  
3. friction increases (effort / resistance)  
4. parent involvement increases  
5. perception shifts from signal → feeling  
6. continuation decision becomes negative  

---

## System Pattern

This is not random.

This is a repeatable pattern:

→ execution instability + perception mismatch  

---

## Boundary Definition

The system is likely to fail when:

- execution is not sustained  
- perception becomes primary evaluation method  
- structure is overridden by external control  

---

## Model Extraction

learning_progress = function(execution)

continuation = function(perception)

---

## Predictive Signal

Early warning signs:

- weekly sessions < 4  
- increasing complaints  
- parent intervention frequency ↑  
- focus shifts from structure → feeling  

---

## Intervention Gap

System currently lacks:

- real-time visibility of structural improvement  
- parent-side evaluation alignment  
- friction management during control phase  

---

## System Insight

Learning systems do not fail at capability.

They fail at alignment:

→ execution  
→ perception  
→ expectation  

---

## Classification

→ EXIT_PATTERN (EXECUTION × PERCEPTION)

---

## One-Line Insight

The system did not lose the student.

The alignment between execution and perception was lost.
