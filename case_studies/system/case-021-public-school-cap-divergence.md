# Case 021 — Public School CAP Divergence

## Context

Comparative group:

- Eric
- Belle
- Ruby

Shared conditions:

- G7 age group
- public-school track
- CAP Reading Judgment diagnostic frame
- same reference system: CAP Playbook × 115 會考閱讀

This case examines why students from a similar public-school context show different CAP Reading Judgment trajectories.

---

## Core Question

Do public-school students form one uniform learning category?

Initial observation:

→ No.

Even within the same age group and school-track environment, CAP outcomes diverge sharply depending on:

- execution stability
- Reading Judgment OS internalization
- decision stability
- precision control
- transfer readiness

---

## CAP System Reference

The CAP Playbook defines the core training target as:

> not English practice, but Reading Judgment.

The key skills include:

- Filtering
- Inference
- Modeling
- Reference Tracking
- Cross-Referencing
- Narrative Logic

The underlying rule:

→ strong readers do not only read more; they read with better judgment.

---

## Student Profile A — Eric

### CAP State

Eric’s issue is not low English ability.

His main gap is that the CAP Reading Judgment System has not become automatic.

Observed weaknesses:

- evidence retrieval not stable
- elimination not automatic
- comparison logic unstable
- decision logic not yet internalized

### Key CAP Risks

- Modeling
- Cross-Referencing
- Reference Tracking
- Decision Stability

### System Interpretation

Eric currently reads more like:

→ sentence-by-sentence reader

rather than:

→ system reader

This creates risk in:

- map questions
- process questions
- multi-step logic
- answer comparison

### Classification

→ CAP_OS_NOT_STABILIZED  
→ MODE-SWITCH_FRAGILITY

## Shared Finding

Public-school students do not form one uniform category.

The key difference is not only school type.

The stronger differentiators appear to be:

- execution stability
- judgment-system internalization
- self-monitoring precision
- tolerance for structured practice
- ability to transfer reading control into output

---

## System Pattern

Same broad demographic group:

→ different CAP trajectory

This suggests that public-school compatibility with JY-OS is not binary.

It depends on whether the student can internalize:

- rule-based reading
- evidence discipline
- comparison logic
- mental modeling
- precision control

---

## Strategic Insight

The useful distinction is not:

→ public school vs international school

The better distinction is:

→ CAP-compatible execution environment vs CAP-incompatible execution environment

---

## Implication for JY-OS

JY-OS should not assume that all public-school students are unsuitable.

However, JY-OS v1 appears to require a minimum compatibility layer:

- stable execution cadence
- parent expectation alignment
- tolerance for invisible structural progress
- willingness to practice reading judgment rather than chase immediate visible output
- ability to accept precision-based correction

Without this layer:

→ progress may remain slow, invisible, or fragile.

With this layer:

→ public-school students may still build advanced reading judgment structures.

---

## Boundary Condition

The system becomes difficult to sustain when:

- family expects visible short-cycle output
- execution is inconsistent
- student resists precision correction
- parent evaluation focuses on feeling rather than signal
- CAP improvement remains structural and not immediately visible

---

## Research Value

This case is important because it separates three ideas that are often confused:

1. English level
2. school environment
3. reading judgment system maturity

The CAP data suggests these are not the same.

A student may have:

- school English ability
- basic grammar control
- vocabulary familiarity

but still lack:

- evidence discipline
- rule detection
- modeling
- comparison logic
- stable reading judgment

---

## Emerging Hypothesis

CAP Reading Judgment can develop in public-school students when:

- execution is sustained
- CAP rules are practiced repeatedly
- mechanical precision is enforced
- evidence-first answering becomes automatic
- output transfer is introduced only after reading-control stabilization
