# Case 018 — Dependency vs Autonomy

## Comparative Context

Reference students:
- Duke
- Eric

## Shared Conditions

- similar age
- same English coaching system
- same execution period
- similar starting level

## Structural Difference

### Duke
- direct communication with coach
- direct email interaction
- student owns execution process

### Eric
- communication mediated through parent
- execution dependent on parental coordination
- lower independent ownership

## Stress Event

Family medical disruption:
- father hospitalized

## Observed Outcome

### Duke-type structure
learning continuity likely survivable

### Eric-type structure
learning paused completely

## System Observation

Execution resilience appears correlated with:
- learner autonomy
- direct system ownership
- independent execution capability

## Emerging Hypothesis

The more dependent the learning architecture is on parental mediation,
the more fragile execution becomes during environmental instability.

## Important Limitation

This is not a capability judgment.

This is an execution-architecture observation.

## System Insight

Independent learning ownership may be one of the strongest predictors of long-term execution continuity.
