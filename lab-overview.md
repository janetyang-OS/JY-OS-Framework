# Reading Judgment Lab

Reading Judgment Lab is a small-cohort experimental learning environment designed to observe how AI-supported coaching influences reasoning development in students.

The lab focuses on **cognitive signals rather than test scores**, tracking how students develop skills such as evidence usage, logical reasoning, and analytical depth over time.

This repository records learning data from multiple students across different learning frameworks.

---

# Mission

The goal of the lab is to document how structured AI coaching can support:

- reasoning development
- evidence-based thinking
- analytical writing
- learning stability across subjects

The lab prioritizes **longitudinal observation** rather than short-term performance improvement.

# Data Structure

Learning data is organized into three layers.

### Student Layer

Individual student learning logs and progress tracking.

Each student folder contains:

- learning-log.md
- metrics.md

---

### Research Layer

Longitudinal observation and experiment records.

This file tracks stability of learning signals such as:

- evidence usage
- reasoning
- structure
- conceptual depth
- response completeness
- pattern recognition

---

# Data Philosophy

The lab tracks **learning signals instead of scores**.

Signals include:

Stable — reasoning and performance consistent  
Developing — improvement in progress  
Needs Attention — additional support required

This approach allows observation of **thinking patterns over time** rather than isolated test results.

---

# Research Purpose

This repository serves as a structured dataset for observing how AI-assisted coaching interacts with student learning.

The goal is to document:

- reasoning development
- learning discipline
- error patterns
- stability of analytical thinking

over extended periods of time.
