# Fix Library (Prescriptions) v0.1

## Purpose
Map diagnosis codes to repeatable micro-actions.
Fixes must include a “dose” so execution is consistent.

---

## Format
**FIX-XXX (Dose):** time / #questions / evidence requirement  
**Use when:** linked error/risk codes  
**Goal:** what stability it tests or repairs

---

## Evidence Fixes
### FIX-E1 (Dose): 1Q → 8 min evidence retrieval → 1 exact sentence
**Use when:** E-EVID-1
**Goal:** force text return + citation habit.

### FIX-E2 (Dose): 2Q → underline support clause + copy exact sentence
**Use when:** E-EVID-2, R-INFER-EDGE
**Goal:** tighten anchor-to-claim alignment.

---

## Inference & Scope Fixes
### FIX-I1 (Dose): 2 inference Q → “because” chain (max 2 links) + 1 evidence sentence
**Use when:** E-INF-1
**Goal:** prevent leaps; keep inference bounded.

### FIX-S1 (Dose): 5 options scan → delete extremes first → cite sentence
**Use when:** E-SCOPE-1
**Goal:** build extreme-filter reflex.

---

## Reference & Time Fixes
### FIX-R1 (Dose): 2 pronoun Q → draw noun map (2 candidates max) → evidence sentence
**Use when:** E-REF-1
**Goal:** stabilize same-gender / competing subject tracking.

### FIX-T1 (Dose): 4Q / 6 min timed → then 8 min evidence retrieval (1 anchor per Q)
**Use when:** E-TIME-1, R-COMFORT-1
**Goal:** test stability under mild pressure while preserving evidence habit.

---

## Distractor & Keyword Fixes
### FIX-K1 (Dose): 3Q → paraphrase question target in 8 words → then answer
**Use when:** E-KEY-1
**Goal:** break keyword lock; restore meaning control.

### FIX-D1 (Dose): 3Q → “question asked vs true detail” check (1 line) → cite sentence
**Use when:** E-DIST-1
**Goal:** stop partial-truth acceptance.

---

## Mapping (Quick Reference)
- E-EVID-1 → FIX-E1
- E-EVID-2 / R-INFER-EDGE → FIX-E2
- E-INF-1 → FIX-I1
- E-SCOPE-1 → FIX-S1
- E-REF-1 → FIX-R1
- E-TIME-1 / R-COMFORT-1 → FIX-T1
- E-KEY-1 → FIX-K1
- E-DIST-1 → FIX-D1
