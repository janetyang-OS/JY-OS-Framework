# Glossary (Philosophy × AI)

## Purpose
A minimal vocabulary to keep worldview discussions operational and consistent.
This glossary is not academic—it is built for **execution** and **assetization**.

---

## Terms (Starter Set)

### Asset (vs Tool)
**Definition:** A durable system artifact that compounds over time (SOP, taxonomy, case library, templates).  
**Common Misunderstanding:** “Assets are content.”  
**JY-OS Note:** Content is disposable; *casework infrastructure* is the asset.

### Evidence
**Definition:** A checkable trace that can support or refute a claim (exact sentence, captured output, recorded reasoning step).  
**Common Misunderstanding:** “Evidence = confidence” or “evidence = correct answer.”  
**JY-OS Note:** Evidence must be *inspectable*.

### Judgment
**Definition:** Choosing what to believe/do under uncertainty using evidence + constraints.  
**Common Misunderstanding:** “Judgment = smart guessing.”  
**JY-OS Note:** Judgment is a workflow, not a talent.

### Answer Dependency
**Definition:** Reliance on external answers (AI/teachers) without internal evidence discipline.  
**Common Misunderstanding:** “If AI is correct, dependency is fine.”  
**JY-OS Note:** Correct answers can still create weak thinking if the process is not validated.

### Assetization
**Definition:** Converting learning and coaching operations into reusable infrastructure (GitHub artifacts).  
**Common Misunderstanding:** “Assetization is documentation for its own sake.”  
**JY-OS Note:** Assetization exists to make execution repeatable and measurable.

## Rule
Every new term added must include:
- definition
- common misunderstanding
- JY-OS note (how it links to execution)
