# Framework Library (Philosophy)

## Purpose
This folder stores reusable mental models used in the AI era.

Each framework page must include:
- 1-sentence thesis
- the model (diagram or structured bullets)
- when to use
- failure modes (common misapplications)
- bridge-to-lab (how it supports evidence-based judgment workflows)
